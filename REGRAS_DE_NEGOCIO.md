# REGRAS DE NEGÓCIO

## Municípios

- Um município pode ser atendido pela Engematsu ou pela West Tractor.
- Cada município pertence a apenas uma região comercial.
- Cada município possui um vendedor responsável.
- Todo município deve possuir um status comercial.

---

## Status Comerciais

- Cliente Ativo
- Em Licitação
- Em Negociação
- Contato Realizado
- Não Atendido
- Prioridade Alta

---

## Visitas

- Toda visita deve possuir data.
- Toda visita deve possuir vendedor.
- Toda visita pode conter fotos.
- Toda visita gera histórico.
- A IA utilizará o histórico para sugerir novas ações.

---

## Frota

- Cada máquina pertence a um município.
- Cada máquina possui histórico de manutenção.
- Cada máquina pode possuir kits de filtros cadastrados.
- Cada máquina pode possuir peças recomendadas.

---

## Licitações

- Toda licitação possui data de abertura.
- Toda licitação possui data de encerramento.
- O sistema deve avisar antes do vencimento.
- O sistema deve gerar alertas automáticos.

---

## Usuários

Administrador:
- acesso total.

Gestor:
- acesso gerencial.

Vendedor:
- acesso somente à sua região.

---

## Inteligência Artificial

A IA deverá:

- analisar visitas;
- analisar licitações;
- sugerir rotas;
- priorizar municípios;
- identificar oportunidades;
- gerar relatórios automaticamente.
