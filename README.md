# Gestor de Municípios

## Objetivo

Desenvolver uma plataforma completa para gestão comercial de municípios, permitindo o gerenciamento de clientes, frotas, licitações, visitas, agendas e indicadores comerciais.

## Empresas

- Engematsu
- West Tractor

## Plataforma

- Computador
- Notebook
- Tablet
- Celular

## Módulos

- Dashboard
- Mapa Interativo
- Municípios
- Frota Municipal
- Licitações
- Agenda
- Relatórios
- Vendedores
- Configurações
- Assistente IA

## Status

🟢 Em desenvolvimento.
