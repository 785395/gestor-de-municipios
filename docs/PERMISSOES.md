# Permissões do Sistema

## Administrador

Acesso total.

Pode:

- Gerenciar usuários
- Alterar configurações
- Cadastrar municípios
- Editar qualquer informação
- Gerenciar vendedores
- Gerenciar licitações
- Visualizar relatórios
- Configurar IA

---

## Gestor Comercial

Pode:

- Visualizar todos os municípios
- Editar municípios
- Editar frota
- Gerenciar agenda
- Criar relatórios
- Acompanhar vendedores

---

## Vendedor

Pode:

- Consultar municípios
- Registrar visitas
- Tirar fotos
- Atualizar contatos
- Atualizar máquinas
- Consultar licitações
- Utilizar Assistente IA

Não pode:

- Excluir municípios
- Alterar configurações
- Excluir usuários

---

## Visitante

Somente leitura.
