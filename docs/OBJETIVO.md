# OBJETIVO DO PROJETO

Desenvolver uma plataforma profissional para gestão de municípios, utilizada pelas empresas Engematsu e West Tractor.

A plataforma deverá permitir:

- Gerenciar municípios.
- Gerenciar contatos.
- Gerenciar a frota municipal.
- Gerenciar licitações.
- Organizar visitas.
- Gerenciar agendas.
- Gerar relatórios.
- Auxiliar vendedores.
- Auxiliar gestores.
- Utilizar Inteligência Artificial para apoiar decisões.

O sistema deverá funcionar em computador, notebook, tablet e celular utilizando um único banco de dados.
